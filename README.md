# 15-Min Book Extractor

Minimal MVP scaffold built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**.

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` - Dashboard
- `/book/new` - New Book
- `/book/[id]` - Book Plan
- `/session/[id]` - Session
- `/summary/[id]` - Summary
